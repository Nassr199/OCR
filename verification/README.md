# Verification harness (optional, not part of the Gradle build)

Paths inside the scripts point to the machine where they were run; adjust them.

| Script | What it proves |
|---|---|
| `gen_vectors.py` + `CoreTest.kt` | Runs the ORIGINAL Python functions (arabic_filter, norm_text, _clean_suspicious_numbers, clean_ocr_output, difflib ratio, merge_entries, merge_ocr_entries) on 11,432 generated cases and checks the Kotlin port gives identical output. Result: 0 differences. |
| `lens_proto.py` + `LensTest.kt` | Decodes the Kotlin-built Lens request with the official protobuf runtime (Chromium field numbers) and re-serialises it byte-identically; builds a Lens response for the Kotlin parser. |
| `gen_video*.py` + `SegTest.kt` | Synthetic 720p/1080p hard-sub video (moving bright background, white flash, yellow text, fades, back-to-back changes); all 7 subtitles found, boundaries within 1 frame. |
| `PipeTest.kt` | Parallel workers, 429 back-off, resume cache, fatal stop with partial results, cancellation, failure breaker. |
| `ApiTest.kt` | Gemini / OpenRouter / Lens request bodies, response parsing and error classification. |
| `vision/VisionTest.kt` | Google Cloud Vision request (key in header, DOCUMENT_TEXT_DETECTION by default or TEXT_DETECTION, language hint of the subtitles), parsing and error classification. |
| `vision/FocusTest.kt` | Google Vision report next to the SRT (`report_sample.txt`) and two-stage reading: when the subtitle shares its row with other text (crew names) or is read unsure, the subtitle's area is cropped from the same picture and read again; the better reading is kept. Areas checked on the measured geometry of real frames. |
| `classic/ClassicTest.kt` | 2.7.6 multi-view reading for Lens (ClassicViews): vote, edge-letter rule, background fragments, pixel reading order, plan of the looks, engine with a fake server. `classic/lens_bench_live.md` = live Lens run (GitHub Actions) on 19 synthetic crops: one look 14/19, the app 17/19. |
| `cache/CacheTest.kt` | Resume memory: per-engine count, readings of a finished Lens/Vision job forgotten (re-runs read afresh), Gemini's kept. |
| `../bench/` + `.github/workflows/ocr-bench.yml` | Live Lens/Vision bench on GitHub Actions (the build sandbox cannot reach Google). Vision runs when the repository has a `VISION_API_KEY` secret. |
| `lens/LensOrderTest.kt` | Google Lens lines in reading order (rows top to bottom, right to left in Arabic) and the same place read twice. |
| `vision/LayoutTest.kt` + `LayoutCommon.kt` + `LayoutFuzz.kt` | Vision text rebuilt from word boxes: same place read twice, blocks laid out left to right, punctuation, two lines, credits, Latin runs; 14,000 random lines (clean reads unchanged, copies removed). |

| `classic/DashTest.kt` | 2.7.8: dialogue dashes — a dash lost on one line restored only from a look that read the same line with it (Lens extra looks, Vision focused look); Vision's focus area keeps a line's own marks (measured geometry); the wrapped single-speaker sentence untouched. |
| `ai/AiTest.kt` | 2.7.8–2.7.9: Gemini and OpenRouter send the same request (v2.6's: its prompt, then the picture; thinking «minimal», «low» for Gemini 4 / 3.8); an answer cut before its end is sent again, never written; OpenRouter errors in plain words (provider 429 vs credit vs free-model limits), key check, refused parameters; adaptive requests in flight under 429; the exact reading's cleaning. |
| `img/BandTest.kt` | 2.7.8: the image enhancement's subtitle band never cuts a line of the subtitle; v2.6's band unchanged where it cut nothing. Run: `java … BandTestKt ../bench/images`. |
| `lens/RepeatTest.kt` | 2.7.9: a place Lens read twice inside one line (letters and shadow) — «… انظري إلي هل تسمعينني؟ هل», «… على الجرح الجرح» — removed by word boxes (real Lens protobuf built in the test); real repeats in two places kept; no word boxes / line-sized boxes untouched; copies in another line, marks, pieces of a word, another hamza. |
| `ai/ConsensusTest.kt` | 2.9.0 «التحقق المزدوج»: two pictures read at once, the same text accepted (tashkeel and spacing aside), a third picture deciding — «خوليا» against «هوليا», two lines joined, «بخير» three times, three different readings (the closest); a failed reading; in the pipeline (counts, the third picture only on a difference, memory key `|x`); Lens never cross-checks. |
| `ai/FrameTest.kt` | 2.9.0 `SubtitleFrame`: on every bench frame the subtitle's frame keeps every drawn letter with room around it (truth.json "text" boxes). |
| `../app/src/test/.../ui/LiquidTest.kt` (Robolectric, workflow "UI screenshots") | 3.0.0: a drag along the tab bar and along the rail reaches every tab from every tab, in both directions (2.9.0 kept the tab it was first drawn with and refused drags back to it); a settings page scrolls on a phone on its side (2.9.0 froze); the liquid switch follows a drag and a tap; the title font loads from memory; the liquid glass shader compiles and takes every uniform the app sets. |
| `../app/src/test/.../core/BlinkTest.kt` (JUnit + Robolectric, workflow "UI screenshots") | 3.0.4: a line the detector cut into pieces (text-like scenery moving behind it) is one line again only with the detector's proof that its text never left the screen (`ScanSegment.continuesId`) AND the same text read (`Arbiter.joinUnbroken`): the user's nine pieces of «أخي» with the proof → one line 04:06.850 → 04:07.716; without the proof nothing is joined whatever the gap; different texts and pieces that read nothing never. A drawn scene (no frame of any video): a car with a number plate, chrome and a grille drives away behind «أخي» — a 25 fps film in a 60 fps file, true 60 fps, a cut into the scene — through the three detectors, the arbiter and «بدون دمج»: one line (3.0.2: eight for the 25 fps film); «لا» then «لا لا» stays two lines. 3.0.5: the 2.1 detector ITSELF gives one piece (one picture) for the car scene (25 fps film, and a cut into the scene), within 6 frames of the start and 3 of the end (3.0.2: eight); it never makes one piece of a line replaced in place («أخي» → «أبي», no gap), the same words after a gap, or «لا» then «لا لا». |
| `glass/preview.py` | 3.0.0: the liquid glass shader's math run on the CPU (numpy) over a picture of the app: the frosted bar, the tinted start button and a held, magnifying lens. Robolectric compiles the shader but cannot run it on its GPU or read pixels back, so the optics are checked here. `python3 preview.py screen.png out.png 3.0 [light]`. |
| `vision/RepeatVisionTest.kt` + `LayoutCommon.kt` | 2.7.9: the same two lines through Google Vision (copy inside the same paragraph): removed; real repeats kept. |

`kc.sh` compiles Kotlin with the compiler embedded in a Gradle distribution:
`./kc.sh out ../app/src/main/java/com/abdulrahman/hardsubocr/core/*.kt CoreTest.kt`
